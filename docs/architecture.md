# 架构说明

> 本文档说明本实践在华为云上的落地方案：组件职责、请求链路、安全模型与数据模型。

---

## 1. 总体结构

```
                    ┌──────────────────────────────┐
   客户端 ──────────▶│  API 网关（专享版）           │
   X-Apig-AppCode    │  · API 分组 / 两条 API        │
                    │  · 应用认证（AppCode）        │
                    │  · 限流策略                   │
                    └──────────────┬───────────────┘
                                   │ 触发器调用
                                   ▼
                    ┌──────────────────────────────┐
                    │  函数工作流（Python 3.9）      │
                    │  · GET  /token → 生成 token   │
                    │  · POST /token → 签发签名 URL │
                    └───────┬──────────────┬───────┘
                            │              │
              宽表协议写入   │              │  签发签名 URL
                            ▼              ▼
              ┌──────────────────┐  ┌──────────────────┐
              │ 宽表数据库        │  │ 对象存储          │
              │ token 条目 + TTL  │  │ 示例对象          │
              └──────────────────┘  └──────────────────┘
                                         ▲
                                         │ 客户端持签名 URL 直取
                                         │
                                      客户端
```

**可选组件**：Web 应用防火墙模块默认关闭。启用后作为域名前置代理回源到网关实例入口，承担表层攻击防护。

---

## 2. 组件职责

| 组件 | 职责 | 关键配置 |
|---|---|---|
| API 网关（专享版） | 接入、鉴权、限流、路由到函数 | 基础版规格；两条 API 发布到同一环境 |
| 函数工作流 | 业务逻辑：token 生成、条件写防重用、签名 URL 签发 | Python 3.9；内存 512 MB；超时 30 s；已加入 VPC |
| 宽表数据库 | token 条目存储与 TTL 自动清理 | 集群形态；兼容宽表协议接口；3 节点 |
| 对象存储 | 示例对象存储 + 函数代码包 | 私有桶（不附加公共策略）；AES256 |
| 统一身份认证 | 函数执行委托 | 全局服务级角色，仅授予对象存储访问 |
| 虚拟私有云 | 实例与函数的网络隔离 | 1 VPC + 1 子网 + 1 安全组 |

## 3. 请求链路

### 3.1 申请 token（GET /token）

1. 客户端携带 `X-Apig-AppCode` 请求网关
2. 网关完成应用认证（失败返回 401/403），限流策略校验窗口内配额（超限返回 429）
3. 网关以触发器方式调用函数，事件体包含 `httpMethod`、`path`、`headers`
4. 函数生成 URL-safe 随机 token，构造条目（`valid=true`、`ttl=created_at+3600`）
5. 函数写入宽表数据库
6. 返回 `{token, expires_at}`

### 3.2 换取签名 URL（POST /token）

1. 网关完成应用认证与请求体校验（`token` 长度 32-100、字符集 `[A-Za-z0-9_-]`）
2. 函数按 `token` 查询条目
3. 条目不存在或 `valid=false` → 返回 403
4. 函数执行**条件写**：`SET valid = :false` 且 `ConditionExpression = "valid = :true"`
   - 条件成功 → 本次为唯一消费方，继续签发
   - 条件失败 → 并发重复消费，返回 403
5. 函数对目标对象签发短期签名 URL
6. 返回 `{presigned_url}`

### 3.3 客户端取对象

客户端持签名 URL 直连对象存储。对象存储校验签名与有效期后返回对象字节。函数不参与数据面传输。

## 4. 数据模型

token 条目（键：`token`）

| 字段 | 类型 | 说明 |
|---|---|---|
| `token` | 字符串 | URL-safe 随机串，主键 |
| `valid` | 布尔 | 单次使用标志；签发出 URL 时由 true 置 false |
| `created_at` | 数值 | 创建时间（Unix 秒） |
| `ttl` | 数值 | 过期时间戳，用于自动清理 |
| `obs_uri` | 字符串 | 目标对象地址，格式 `obs://<bucket>/<key>` |

表在首次写入时自动创建，无需预先建表。

---

## 5. 安全模型

| 层面 | 措施 |
|---|---|
| 接入鉴权 | 应用认证（`X-Apig-AppCode` 头），仅持密钥的客户端可调用 |
| 速率限制 | 限流策略按时间窗约束单 API 请求量 |
| 防重放 | 条件写保证 token 只能被消费一次；并发场景下仅一方成功 |
| 时效控制 | token 有 TTL；签名 URL 默认 300 秒有效 |
| 数据隔离 | 桶为私有且不附加公共策略，对象不暴露匿名读取 |
| 加密 | 桶级服务端加密（AES256） |
| 权限最小化 | 函数执行委托仅授予对象存储访问；数据库采用实例账号鉴权 |
| 凭据管理 | 访问密钥仅通过环境变量提供给 IaC 工具，不落盘 |

---

## 6. 网络与访问路径

- 函数与宽表实例部署在同一 VPC，函数通过内网地址访问数据库
- 宽表数据面端口随部署形态而定：集群形态使用 **80**
- 客户端经公网访问网关入口；对象取用由客户端凭签名 URL 直连对象存储

---

## 7. 可观测性

- 函数已开启日志上报，运行日志可在「函数工作流 → 函数 → 日志」查看
- 网关侧访问日志与监控指标可在控制台按需开启
- 日志级别由 `function_log_level` 变量控制

## 8. 实施注意

1. **数据库鉴权方式**：宽表协议兼容接口的数据面只接受实例账号与实例管理员密码，不接受统一身份的临时凭据，也不支持会话令牌。函数侧因此以实例账号作为静态凭据。
2. **可用区参数形态**：集群形态下可用区是逗号分隔的字符串，需覆盖 3 个可用区；单节点形态才可用单可用区。
3. **数据面端口**：集群形态为 80，单节点形态为 8000，需按实际形态配置。
4. **桶策略**：函数以委托临时凭据签发签名 URL，客户端凭 URL 取对象时按签名主体权限校验，因此需为委托放通目标对象的读取权限。
5. **代码包对象**：函数以对象存储方式加载代码包，代码包变更后需重建函数以重新拉取（模块已配置自动重建）。
6. **可选防火墙**：该服务为可选付费服务，默认不启用。
